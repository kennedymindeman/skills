# Memes

`~/wiki/memes.md` is the collection. Each entry has a When line.

- When a situation fits an entry's When line, send the user that meme.
- When the user pastes an image and calls it a meme, save the image to `~/wiki/memes/` and add an entry to `~/wiki/memes.md`.
